# Pro 订阅与激活条款

> 本文件说明 **Pro 功能** 的付费订阅与激活规则。  
> 源代码按仓库根目录 [MIT License](../LICENSE) 授权；**订阅/激活是独立于 MIT 的商业服务**，仅决定官方构建中 Pro 能力是否可用。

---

## 1. 与 MIT 的关系

| 层面 | 适用文档 |
|------|----------|
| 源码使用、修改、再分发 | [LICENSE](../LICENSE)（MIT） |
| Pro 功能、激活码、设备绑定 | 本文 + [`wps-activation-policy.md`](./wps-activation-policy.md) |

MIT 允许任何人自行构建、修改、分发本软件。官方发布的安装包中，部分能力仍通过 **LicenseHub 在线激活** 启用 Pro；未激活时可使用文档列明的免费/基础功能。

## 2. 订阅与 Pro 权益

- Pro 采用 **订阅制**，价格、期限与权益以官方渠道公布为准。
- 订阅有效期内：可获得 Pro 功能、软件更新与相应技术支持（以实际提供为准）。
- 订阅期满且未续费：Pro 功能停止，可继续使用 MIT 许可范围内的基础能力（以产品内门禁为准）。

## 3. 激活与设备

- 激活码格式、在线激活/解绑 API、设备指纹与错误处理见 [`wps-activation-policy.md`](./wps-activation-policy.md)。
- 一码一设备等规则以激活政策与 LicenseHub 平台配置为准。

## 4. 免责声明

- 软件按「现状」提供；MIT 许可中的免责条款同样适用于官方构建。
- 文件处理均在用户本机完成，不上传用户表格内容；用户须自行备份数据。

## 5. 其他

- 官方渠道与联系方式以发布页/应用内说明为准。
- 条款更新后，继续使用官方 Pro 服务即视为接受新版条款。
