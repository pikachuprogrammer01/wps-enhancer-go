## 1. 与 LICENSE 的关系

| 层面 | 适用 |
|------|------|
| 源码可见、个人非商业使用 | [`LICENSE`](../LICENSE) 第 1.2 条（免费） |
| 公司 / 组织 / 商业使用 | [`LICENSE`](../LICENSE) 第 1.3 条（须付费） |
| Pro 功能、激活码、设备绑定 | 本文 + [`wps-activation-policy.md`](./wps-activation-policy.md) |

仓库可公开浏览，**不是** MIT/OSI 开源；公司使用不能仅因「能看到源码」而免费。

## 2. 谁需要付费

**须付费（商业 / 组织授权或订阅）：**

- 公司、企业、个体工商户、机关、学校、团队等组织使用  
- 员工在工作中使用  
- 用本软件对外提供有偿服务或支撑生产经营  

**可免费：**

- 自然人个人、非商业自用（学习 / 研究 / 私人整理通讯录等）

价格、席位与期限以官方渠道为准；付费后通过 LicenseHub 激活码启用约定能力。

## 3. Pro 订阅与激活

- 期满未续费：应停止商业 / 组织使用；个人非商业使用仍受 `LICENSE` 约束。  
- 激活码格式、在线激活/解绑、设备指纹见 [`wps-activation-policy.md`](./wps-activation-policy.md)。
